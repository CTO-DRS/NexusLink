# NexusLink v0.1.0 — ملاحظات الإصدار / Release Notes

> التاريخ: 2026-11-26 · أول إصدار بالترقيم الجديد: يبدأ المشروع رسميًا من v0.1.0 (الإصدارات السابقة محفوظة كما هي).
> Date: 2026-11-26 · First release under the new numbering: the project officially restarts at v0.1.0 (earlier releases are kept as they are).

---

## العربية

- **ترقيم جديد:** v0.1.0 هو أول إصدار رسمي؛ لا توجد ترقية من 3.x، ثبّت من جديد.
- **توقيع رسمي جديد:** مفتاح توقيع أندرويد جديد ومفتاح محدّث سطح المكتب جديد؛ لا تتوافق هذه التثبيتات مع حزم 3.x الموقّعة بمفاتيح قديمة.
- **الأمان:** رمز اقتران إلزامي لغير loopback على البوابة، وأندرويد بلا خدمات سحابية (ZXing بدل ML Kit)، وترويسات أمان مُحكمة.
- **أندرويد:** APK مقسّم لكل معمارية (arm64-v8a / armeabi-v7a / x86_64) + AAB، الحد الأدنى Android 8.
- **المنصات:** Windows (NSIS/MSI/Portable) · macOS (DMG، غير موقّع من Apple) · Linux (AppImage/deb) · Android.
- **حدود معلنة:** لا توقيع Authenticode لويندوز ولا Notarization لماك بعد؛ المرآة والاقتران لم يُختبرا على أجهزة حقيقية آليًا بعد.

## English

- **New numbering:** v0.1.0 is the first official release. There is no upgrade path from 3.x; install fresh.
- **New official signing:** new Android signing key and new desktop updater key. These builds do not upgrade over 3.x builds signed with the old keys.
- **Security:** pairing token required for any non-loopback gateway access, Android without cloud SDKs (ZXing instead of ML Kit), hardened security headers.
- **Android:** per-ABI APKs (arm64-v8a / armeabi-v7a / x86_64) plus AAB, minimum Android 8.
- **Platforms:** Windows (NSIS/MSI/Portable) · macOS (DMG, not Apple-notarized) · Linux (AppImage/deb) · Android.
- **Known limits:** no Windows Authenticode signing or Apple notarization yet; mirroring and pairing are not yet automatically tested on real devices.
