## العربية

### إصلاحات
- **قاعدة أولية نظيفة:** الحزم تشحن `custom.db` فارغة تمامًا (26 جدولًا، صفر صفوف) عبر `scripts/make-clean-seed.mjs`، والبناء يفشل إن بقي صف واحد — لا بيانات تجريبية تصل للمستخدم.
- **deb/AppImage:** عميل Prisma المجزّأ يُنسخ نسخًا فعليًا داخل `.next/node_modules`، فتعمل مسارات قاعدة البيانات بدل خطأ 500.
- **حجم وخصوصية:** حذف 73 ملف source map من الحزم.
- **أندرويد:** `allowBackup=false` و`fullBackupContent=false`، وتقليص APK إلى arm64-v8a وarmeabi-v7a وx86_64.
- **الهوية:** شعار NexusLink (الوصلة) بدل أيقونة Z الموروثة من القالب في الأيقونة المفضلة وصفحة التحميل.
- **CI:** تحديث `bun.lock` إلى v3 لإصلاح فحص «lockfile frozen».

## English

### Fixes
- **Clean seed database:** packages now ship an empty `custom.db` (26 tables, zero rows) built by `scripts/make-clean-seed.mjs`; the build fails if any row remains.
- **deb/AppImage:** the hashed Prisma client is copied for real into `.next/node_modules`, so database routes work instead of returning 500.
- **Size and privacy:** 73 source maps removed from the bundles.
- **Android:** `allowBackup=false`, `fullBackupContent=false`; APK trimmed to arm64-v8a, armeabi-v7a and x86_64.
- **Branding:** the NexusLink link mark replaces the leftover template "Z" logo in the favicon and download page.
- **CI:** `bun.lock` regenerated (v3) to fix the frozen-lockfile check.
