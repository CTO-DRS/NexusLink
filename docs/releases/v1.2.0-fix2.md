## العربية

**NexusLink v1.2.0** — الروتينات الذكية تتقابل مع تاريخ الصحة: «نبّهني إذا كانت بطارية X تحت 15% لمدة ساعة» تعمل حرفيًا — حتى وأنت نائم.

### جديد

**مشغّلات تاريخية بمدة** — أربعة مشغّلات تُقيَّم على سلسلة دليل من عينات الصحة المؤرشفة (عينة كل 30 ثانية لكل جهاز): بطارية تحت العتبة لمدة، استجابة (RTT) فوق العتبة لمدة، صمت بلا نبض لمدة، وتخزين فوق العتبة لمدة — المدة 1..1440 دقيقة، والقيمة تُؤرشف مع كل عينة فيُثبت الشرط تاريخيًا لا لحظيًا فقط.

**نبض الخدمة الذاتي** — القياس صار خاصية الخادم لا المتصفح: نبضة كل 4 ثوانٍ تولّد العينات حتى بلا أي واجهة مفتوحة — «بطارية تحت 15% لمدة ساعة» تُثبت على مدار الساعة؛ وإيقاف عملية الخادم إيقاف موثق يُستأنف عند الإقلاع وتحكمه فجوات التسامح.

**تنبيهات لا تتبخر** — كل إطلاق يُرسَّخ في سجل دائم (سقف 200) بدلالة رؤية صادقة: عميل متصل = رؤية عند التسليم؛ صفر عملاء = «لم يُرَ» بشارة كهرمانية وملخص عودة عند أول اتصال جديد وزر «تعليم الكل كمقروء» — والسجل يبقى بعد إعادة تشغيل الخادم كاملة.

**قواعد دائمة** — الروتينات تُرسَّخ في SQLite وتُستعاد حرفيًا بإحصاءاتها عند الإقلاع؛ حذف قاعدة بذرية يبقى حذفًا؛ «شغّل الآن» يُرسّخ عدّاد التشغيل؛ وإحصاءات كل قاعدة (تشغيلات اليوم/الكل/آخر إطلاق) دائمة.

**حافة بلوغ الشحن** — المشغّل اللحظي battery.above: «نبّهني عندما تصل بطارية X إلى 80%» بعبور صاعد وإعادة تسليح معكوسة (−5) — فك الشاحن في وقته.

**«فحص التاريخ الآن» من المحرر** — قبل الحفظ: حكم فوري أخضر/كهرماني من مقيّم المحرك نفسه حرفيًا، بالسبب المسبب ورقائق الدليل (عينات/تغطية/عمر المرساة/آخر عينة) وشارة صدق للنتائج القديمة — قراءة محضة بلا أي أثر (لا سجل ولا ترسيخ ولا تسليح) + اختيار الجهاز من قائمة الاقتران الحي مع إدخال يدوي للأجهزة غير المدرجة.

**الهاتف: التحكم هاتفًا وهاتفًا + مركز فك الحجب** — تطبيق الهاتف يضاف إليه التحكم بالهاتف الآخر من عارض الهاتف الأول، ومركز فك الحجب (Unblock Center) — مع خدمة مشاركة الشاشة المحدثة وجسر النواة المحسّن.

### حدود موثقة بصدق

- دقة المشغّلات اللحظية = إيقاع الاستطلاع (4 ثوانٍ) ودقة التاريخ = إيقاع العينات (30 ثانية/جهاز).
- سجل التشغيل الآني (آخر 80) بذاكرة الجسر ويبدأ نظيفًا عند الإقلاع — الدائم هو سجل الإطلاقات (سقف 200).
- عينات ما قبل ترقية عمود التخزين تُقرأ 0 — سلسلة الدليل تبدأ من أول عينة بعد الترقية.
- المقطوع أثناء المدة يخالف السلسلة رغم بقاء قيمته المؤرشفة — متطلب الاتصال صادق.
- «فحص التاريخ» يجيب عن «الآن» حصرًا — لا يضمن المستقبل.

## English

**NexusLink v1.2.0** — smart routines meet health history: "notify me if device X's battery stays under 15% for an hour" works literally — even while you sleep.

### New

**Sustained (history-based) triggers** — four triggers evaluated over an evidence chain of archived health samples (one sample every 30s per device): battery below threshold for a duration, response (RTT) above threshold for a duration, silence (no pulse) for a duration, and storage above threshold for a duration — duration 1..1440 minutes; the value is archived with every sample so the condition is provable historically, not only at the instant.

**Autonomous service pulse** — measurement now belongs to the server, not the browser: a 4-second pulse generates samples with zero UI open — "battery under 15% for an hour" is provable around the clock; stopping the server process is a documented pause, resumed on boot with gap tolerance.

**Durable alerts** — every fire is persisted to a durable log (cap 200) with honest visibility semantics: a connected client = seen on delivery; zero clients = "unseen", shown with an amber badge, a back-summary on the next connection, and a "mark all as read" action — the log survives full server restarts.

**Durable rules** — routines are persisted to SQLite and restored verbatim with their stats on boot; deleting a seeded rule stays deleted; "run now" persists the run counter; per-rule stats (runs today/total/last fired) are durable.

**Charge-complete edge** — the instant trigger battery.above: "notify me when X's battery reaches 80%" with a rising edge and mirrored re-arm (−5) — unplug the charger on time.

**"Test history now" in the editor** — before saving: an instant green/amber verdict from the very same engine evaluator, with the exact failing reason and evidence chips (samples/coverage/anchor age/last sample) plus a staleness badge for stale results — pure read with zero side effects (no log, no persistence, no arming) + a device picker fed from live pairing, with a manual-ID escape hatch for unlisted devices.

**Mobile: phone-to-phone control + Unblock Center** — the phone app gains controlling the other phone from the first one's viewer, plus the Unblock Center — with an updated screen-share service and an improved native bridge.

### Honest limitations

- Instant-trigger precision = the 4s poll; history precision = the 30s-per-device sampling cadence.
- The in-memory run log (last 80) lives in the bridge and starts clean on boot — the durable one is the fire log (cap 200).
- Samples predating the storage-column upgrade read as 0 — the evidence chain starts at the first post-upgrade sample.
- Disconnection during a duration violates the chain even though the archived value remains — the connectivity requirement is honest.
- "Test history now" answers "now" only — it guarantees nothing about the future.

### Release engineering

- Version **1.2.0** unified across all platforms (Windows/macOS/Linux/Android).
- Arabic/English release notes attached automatically to every release tag.
- Signed updater assets (latest.json + SHA256SUMS) are generated by the same green release pipeline.
- The **1.1.0 → 1.2.0** upgrade path preserves all settings (the user's SQLite database is never touched; new tables are additive only) — local E2E suite **585/585**.
