## العربية

**NexusLink v2.0.0** — إصدار المنظومة المفتوحة والذكاء المحلي: منصتك تبحث عن
كل شيء، تسألها، تُبشّر تكاملاتك، وتتوقع روتيناتك — وكل ذلك لم يغادر جهازك بايتًا واحدًا.

### جديد

**الذكاء المحلي (عقد §33)** — طبقة ذكاء كاملة على الجهاز: بحث موحد عبر ثمانية
مخازن محلية (أجهزة/روتينات/حافظة/رسائل/جهات/نداءات/تسليم/ملفات) بدرجات بادئة
فاحتواء فتسلسل من نافذة واحدة (Ctrl+Shift+F)؛ مساعد على الجهاز بخمس نوايا
حتمية (status/find/suggest/explain/help) بإجابات مسببة من الفهرس المحلي، مع
محول LLM محلي اختياري بحرس 127.0.0.1 حصرًا (Ollama/llama.cpp — وصفر تثبيت
إلزامي: بلا مُشغّل يخدم المحرك الحتمي كاملًا بصدق)؛ مشغلات روتين مركبة تجمع
شرطًا تاريخيًا مع حالة الآن بتنبيهات تفسيرية بذليل يبقى بعد إعادة التشغيل؛
ولوحة رؤى بسلسلة 14 يومًا متصلة من الجداول القائمة حصرًا.

**المنظومة المفتوحة (عقد §34 — إصدار العقد 2.0)** — SDK 2.0 عميل ESM صفر-اعتماد
بحرس محلي صارم في البناء؛ واجهات REST عامة فوق جسر الأتمتة نفسه بصفر ازدواج
تحقق (`/api/automation/rules` و`/api/sync/ops` قراءة حصرًا)؛ سوق تكاملات
«تصريحية لا تنفيذية» — توقيع HMAC-SHA256 بثنائية زمن-ثابت وكتالوج قدرات مغلق
وقناة بداية بعشرة تكاملات موقعة تُثبَّت بضغطة؛ وCLI صفر-اعتماد يعيد استخدام
الـSDK بأوامر 16 (status/devices/ops/search/ask/insights/automation/market…)
— والدليل الكامل: `docs/sdk-guide.md`، والمكونات المفتوحة معلنة في
`docs/OPEN-COMPONENTS.md` (pair-math · oplog · sdk/ · cli/ بترخيص MIT).

**عمق ما بعد M3 (عقد §35)** — قناة الناشر المركزية: سجل صفر-مخطط بتدوير مفاتيح
بإصدارات يحفظ القديم وإبطال لحظي وغلاف pub بثنائية توقيع على القناة كلها
وتثبيت بمسارين وبصمات حصرًا لا مفاتيح؛ الفرض اللحظي للقدرات: أصل قاعدة
`origin.plugin` وبابا الإنشاء والإطلاق عبر `isPluginLive` مصدر الحقيقة الواحد
وتوقف بصدق `ok=false` مسبب والإحياء يحفظ الأصل؛ والتنبؤ الاستباقي الحتمي:
نمط يومي بذات اللحظة ووسيط فترات من تاريخ الإطلاقات واقتراحات مسبّبة بالدليل
— تبويب «التنبؤ» الثالث والإنشاء بيد المستخدم حصرًا.

**العميل الوِب المستقل (عقد §36)** — منظرٌ لا باب: أثر ثابت صفر-بناء في
`public/web-client/` تخدمه الجهاز نفسها فوق الأسطح الثمانية القائمة حصرًا
(صفر مسار API جديد) — صفر بايت خارجي مفحوص، ترجمة مضمنة 114/114 متوازنة،
PWA standalone قابل للتثبيت، ووضع TV/لوحات قراءة حصرًا مفروض في العميل نفسه
— تفتح على أي شاشة في شبكتك من متصفح بلا أي تثبيت.

**الوصول البعيد برمز اقتران (عقد §37)** — البوابة OFF افتراضيًا وبلا ملف رمز
صالح فالسلوك حرفيًا كما كان؛ عند التمكين: حسم لكل واصل من خارج الجهاز بترويسة
`x-pair-token` بمقارنة زمن-ثابت sha256، حجب تجريبي 5 فشل→30ث لكل IP، الرمز
لا يغادر البوابة (يُجرَّد قبل التحويل HTTP وWS) ولا يُعرض مرتين، الإدارة
loopback حصرًا عبر `/api/remote-access` (تمكين/تدوير/تعطيل بصمات صادقة) —
البطاقة في الإعدادات والعميل الوِب يمرر الرمز ترويسة في السلك حصرًا.

**حدود صادقة بصدق الوثائق** — ما يبقى خارجيًا بعد هذا الإصدار: TLS/النفق/النطاق
للوصول عبر الإنترنت والنشر المؤسسي (M4)؛ توقيع Windows codesign وnotarization
ماك (بنود الثلاثين يومًا)؛ دقة LLM المحلي حسب المُشغّل المثبت والبديل الحتمي
يغطي النوايا الخمس دائمًا؛ ووضع TV للعرض والقراءة حصرًا لا للإدارة.

**التوثيق المرفق** — `docs/MASTER-PLAN.md` خطة التنفيذ التشغيلية الشاملة
(جرد الواقع · إدارة الإصدار · المسار الخارجي بمعايير قبول · مؤشرات ومخاطر)،
و`download/NexusLink-خارطة-الطريق-التنفيذية.pdf` الوثيقة الرسمية (11 صفحة RTL).

## English

**NexusLink v2.0.0** — the open-platform & local-intelligence release: your
hub searches everything, answers questions, hosts your signed integrations,
and predicts your routines — without a single byte leaving your machine.

### What's new

**Local intelligence (contract §33)** — a full on-device intelligence layer:
unified search across eight local stores (devices/routines/clipboard/messages/
contacts/calls/transfers/files) with prefix > substring > sequence scoring in
one window (Ctrl+Shift+F); an on-device assistant with five deterministic
intents (status/find/suggest/explain/help) answering with evidence from the
local index, plus an optional local LLM adapter strictly guarded to 127.0.0.1
(Ollama/llama.cpp — zero mandatory installs: without a runner the deterministic
engine serves honestly); composite routine triggers combining a historical
condition with present state, with explanatory alerts whose evidence survives
reboots; and an insights board with a connected 14-day series built exclusively
from existing tables.

**Open platform (contract §34 — contract v2.0)** — SDK 2.0, a zero-dependency
ESM client with a strict local-only guard at build time; public REST surfaces
over the same automation bridge with zero duplicated validation
(`/api/automation/rules`, `/api/sync/ops` read-only); a declarative (never
executive) integration marketplace — HMAC-SHA256 signing with
constant-time comparison, a closed capability catalog, and a starter channel
of ten signed one-click integrations; and a zero-dependency CLI reusing the
SDK with 16 commands. Full guide: `docs/sdk-guide.md`; open components
declared in `docs/OPEN-COMPONENTS.md` (pair-math · oplog · sdk/ · cli/, MIT).

**Post-M3 depth (contract §35)** — the central publisher channel: a
zero-schema registry with versioned key rotation preserving history and
instant revocation, a dual-signed pub wrapper over the whole channel,
dual-path installation, fingerprints only (never keys); live capability
enforcement: rule origin `origin.plugin`, creation/launch gates via
`isPluginLive` as the single source of truth, honest `ok=false` stops with
reasons, revival preserving origin; and deterministic predictive suggestions:
same-time-of-day daily patterns, inter-arrival medians from launch history,
evidence-backed proposals — a third "Predict" tab, user-created only.

**Standalone web client (contract §36)** — a view, not a gate: a fixed
zero-build artifact in `public/web-client/` served by the device itself over
the eight existing surfaces only (zero new API routes) — verified zero
external bytes, balanced embedded translation 114/114, installable standalone
PWA, and a TV/read-only dashboards mode enforced inside the client itself —
open it on any screen in your network from a browser, no install.

**Remote access with a pairing token (contract §37)** — the gateway is OFF
by default; with no valid token file the behavior is literally unchanged.
When enabled: every off-device caller is decided by an `x-pair-token` header
with constant-time sha256 comparison, 5-failure→30s lockout per IP, the token
never leaves the gateway (stripped before proxying, HTTP and WS) and is shown
only once, administration is loopback-only via `/api/remote-access`
(enable/rotate/disable with fingerprint responses) — settings card included,
web client sends the token as a wire header only.
