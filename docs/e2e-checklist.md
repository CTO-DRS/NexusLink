# NexusLink — قائمة تحقق التكامل النهائية (E2E بجهازين حقيقيين)

**الطريقة**: هاتف حقيقي (Android) + كمبيوتر حقيقي على **نفس شبكة Wi-Fi**، والحزم
المُثبَّتة من [GitHub Releases](https://github.com/CTO-DRS/NexusLink/releases/latest) —
لا شيء مبني محليًا ولا بيئة تطوير.

**دلالة الأعمدة**:
- ✅ آليًا = مثبتة بجولات تحقق آلية ضد سيرفرات حية (E2E 90/90 · media-verify 38/38 ·
  agent-* suites · hardening-verify · analyze صفرية · CI 3/3) — عمود النتيجة يُعبأ
  للتأكيد الميداني فقط.
- 🖐 يدوي حصريًا = يتطلب عتادًا فعليًا (بصمة/بطارية/WebView2/ميكروفون Zoom) — لا
  يمكن إثباته في CI، وهذا موثق بصدق في §9 من العقد.

## حدود موثقة بصدق (لا تُخفى)

- **iOS**: بلا SMS/مكالمات وبعض خدمات الخلفية — قيود Apple.
- **24 ساعة بطارية/ذاكرة**: القياس الميداني يتطلب جهازًا فعليًا ليلًا كاملة (10.6)؛
  آليًا: baseline ذاكرة قصير + سياسة خمول موثقة.
- **macOS**: DMG غير موقّع (يتطلب حساب Developer — دليل التوقيع في BUILD.md §3).
- **Windows SmartScreen**: التنفيذ غير موقّع Authenticode — تحذير أول تشغيل
  «More info → Run anyway» (اختياري: شراء شهادة وتوقيع CI).
- قياس السرعة الداخلي يقيس **الشبكة المحلية** فقط.
