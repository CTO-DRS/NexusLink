### 1.د ما هو مكتمل خارج الوسائط ويبني عليه الجولة
- **جلسة التحكم الموثوقة (§13)**: `rc:session start|hb|stop` + حاجز ثقة مزدوج (سوكِت مسجل + سجل أجهزة) + watchdog مزدوج (جسر 6ث نبض / Rust 15ث خمول) + حقن `__src` — والبوابة الحاسمة: `input::execute` يرفض `source!="desktop-local"` بلا جلسة نشطة — `input.rs:262-273`.
- **الماوس الهوائي TCP موجود أصلًا**: `controller_service.dart:508-540` — جيروسكوب `sensors_plus` 50ms → تنعيم أُسي (α=0.55, deadzone 0.02 rad/s, gain 220) → `rc:move` عبر socket.io. **ثغرة الأداء**: فوق TCP (head-of-line + Nagle + إعادة إرسال) — الجولة 4 تنقل الإدخال الحي إلى UDP.
- **`rc:presenter` منفّذ أصليًا** (`apply_presenter`: next/prev/start/stop/black + laser موثق كعرض ويبي فقط) — `input_exec.rs:337-367`.
- **`sensor:stream`** على 3005 (هاتف→ويب، تنقية a/g + معدل) — تعليق المصدر: «للويب كجيمباد لاحقًا». لم يستهلكه سطح المكتب قط.
- قياس الكمون القائم: `rc:ping/pong` كل 6ث → `latencyMs` (socket.io، لا يصلح للإدخال الحي).

## 3. ما هو مكسور / حدود صادقة يجب ألا تُخفى

1. **لا شيء مكسور معروف الآن** — آخر حالة خضراء: CI 3/3 (desktop) + Release + E2E 127/127 + media-verify 38/38 (WebRTC loopback حقيقي: 20 إطار H264 + 40 حزمة Opus عبر RTP فعليًا).
2. **حدود موثقة لا تُعالج هذه الجولة إلا بذكرها**: ماك — قيود توقيع akvirtualcamera (OBS بديل)؛ لينكس Wayland — بلا حقن إدخال أصلي (X11/XWayland فقط) وبلا كشف خمول؛ iOS — لا SMS/مكالمات (خارج نطاق الوسائط).
3. **درس CI متكرر يلزم الجولة**: أي كرِيت جديد يُتحقق من مصدره (codeload/crates.io) قبل الاستخدام — النمط القاتل السابق: ميزات مخترعة (`CGWindowGetBounds`، ميزة LAPolicy) تُكتشف متأخرًا.
4. **v1.0.0 مقفولة** في الملفات الأربعة — أي عمل جديد لا يمس الإصدار ولا الأصول الموقعة.

## 4. أساس الجولة المشترك: قناة NexusLive (UDP) — التصميم المرجعي

> التفاصيل التعاقدية الكاملة ستوثق في §18 من العقد عند التنفيذ. هذا ملخص القرار المرجعي.

### 4.أ طوبولوجيا المسار
```
هاتف (Flutter) ──UDP :3010──▶ جسر 3004 (Node/dgram — بوابة الثقة + إحصاء)
                                   │ إعادة توجيه loopback
                                   ▼
                              127.0.0.1 :3011 ──▶ live.rs (Rust/Tauri)
                                   │ فك binary → أحداث JSON
                                   ▼
                              input::execute (بوابة §13 القائمة) → input_exec (enigo)
```
- **لماذا تمرير عبر Node لا إرسال مباشر للهاتف→Rust؟** (قرار معماري مُسوّى):
  بوابة الثقة مركزية عند الجسر (controllerTrust + rc:session قائمة) — إحصاء الفقد/الترتيب/RTT قابل للرصد من E2E (فحوص التعاقد تعمل Node-side)، وRust يبقى مستقبلًا معزولًا على loopback فقط (سطح هجوم أدنى — نمط الحد الأدنى للصلاحيات المعتمد في التقوية).
  كلفة الحلقة المحلية: عشرات الميكروثانية — لا تهدد هدف 20ms.
- **المنافذ**: `3010/udp` هاتف→جسر (NEXUS_LIVE_PORT) · `3011/udp` جسر→Rust على 127.0.0.1 حصرًا (NEXUS_LIVE_SINK_PORT). لا تعارض مع المنافذ الثمانية القائمة (81/3000/3003/3004/3005/3006/3007/3009).
- **الثقة**: `rc:live-hello` فوق socket.io (هاتف موثوق + جلسة نشطة فقط) → `rc:live-ready {port, key, mtu, proto}` بمفتاح 8 بايت عشوائي لكل جلسة → أول حزمة UDP تحمل المفتاح تُثبّت عنوان المرسل (رفض ما بعده من عنوان آخر) → نهاية الجلسة/انقطاع السوكِت تحذف التدفق فورًا.

### 4.ب البروتوكول الثنائي (NexusLive v1 — big-endian، حزمة واحدة دائمًا ≤34B)
```
رأس ثابت 22 بايت (كل الأنواع):
  [0..2)  u16be  magic = 0x4E58 ("NX")
  [2]     u8     version = 1
  [3]     u8     type: 1=pen 2=mouse 3=gyro 4=touch 0x7F=ping (0x7E=pong من الجسر)
  [4]     u8     flags (bit0 = نسبي لحزمة mouse)
  [5]     u8     reserved (0)
  [6..10) u32be  seq (تسلسل تصاعدي لكل تدفق — للفقد/الترتيب/التكرار)
  [10..14)u32be  ts (ms epoch & 0xFFFFFFFF — بعد مزامنة الإزاحة عبر pong)
  [14..22) 8B    key (مفتاح الجلسة)
حمولات (مجموع الحقول حرفيًا — هذا هو التعاقد المُطبق في live_core.rs وlive_channel.dart):
  pen   10B: nx u16be · ny u16be · pressure u16be (0..65535) · tiltX i8 · tiltY i8 · phase u8 (0=hover 1=down 2=move 3=up) · buttons u8
  mouse  8B: nx|dx · ny|dy · phase u8 (0=move 1=down 2=up 3=click 4=dblclick 5=rclick) · buttons u8 (bit0=أيسر مضغوط) · wheel i16be
             — flags bit0 = 0 ⇒ nx/ny مطلقة u16be 0..65535 (مؤشر عرض تقديمي) · 1 ⇒ dx/dy نسبية i16be ±500 بكسل (ماوس هوائي)
  gyro  12B: ax/ay/az i16be (milli-g) · gx/gy/gz i16be (milli-dps)
  touch  8B: nx u16be · ny u16be · action u8 (كإجراءات pointer الست) · pointerId u8 · pad u16
  ping    0B — يرد الجسر pong بنفس seq وts=زمن الجسر (مزامنة إزاحة NTP-نمط)
```
- **ضبط حزمة واحدة**: كل حدث = داتاجرام واحد (34B أقصى = 22 رأس + 12 أوسع حمولة) — لا تجزئة ولا تجميع عبر الأحداث.
- **التحويل**: mouse نسبي → `kind=move {dx,dy,drag:buttons.bit0}` في كل حزمة (حالة الزر مطلقة في كل حزمة — دلالة حية ذاتية التصحيح ضد فقد الحزم؛ حافة السحب تُحسب في set_drag) + حدث click إضافي عند phase=click/dblclick/rclick · mouse مطلق/pen/touch → `kind=pointer`.
- **دلالة حية**: لا إعادة إرسال ولا تخزين مؤقت — الفقد يُعدّ إحصاءً فقط (أحدث حالة تفوز).
- **التحويل للتنفيذ** (بلا مسار حقن موازٍ): pen/touch/mouse → أحداث `kind=pointer` القائمة (المطبّع + الإجراءات الستة) — pressure تُحمل في الحمولة وتصل لمحلّق الإدخال استعدادًا لمهمة لوحة الرسم؛ wheel في mouse → `kind=scroll` القائم؛ gyro → يُعدّ إحصاءً فقط هذه المرحلة (مستهلكه مهمة الجيمباد).
- **الكمون طرف-إلى-طرف**: ts من ساعة الهاتف + إزاحة مقدرة من ping/pong (NTP-نمط) → Rust يقيس `now - ts` عند الحقن ويحسب P50/P95 (متاح عبر أمر `live_state`).

### 4.ج الأهداف الرقمية للجولة (مقيسة لا مزعومة)
| القياس | الهدف | آلية القياس |
|---|---|---|
| إدخال قلم <20ms | طرف-إلى-طرف (ts الهاتف → ما بعد الحقن) | حقل ts + إزاحة pong + P95 في live_state |
| ماوس هوائي <30ms | نفس الآلية | نفسها |
| شاشة ثانية <80ms | مرحلتها الخاصة لاحقًا | مرحلتها |
- **الإثبات التنفيذي**: `scripts/live-verify` (نمط media-verify المعتمد): يضمّن live_core.rs + input_exec.rs حرفيًا، يدوّر UDP loopback حقيقي عبر Xvfb (enigo يعمل)، يقيس كمون الحقن الفعلي ويجتاز عتبة 20ms على الحلقة المحلية + متجهات فاسدة تُرفض.
- **الإثبات التعاقدي**: E2E §18 — فقد/ترتيب/RTT/رفض بلا جلسة/رفض مفتاح فاسد/تثبيت العنوان/توقف التمرير عند نهاية الجلسة.

### 4.د قائمة التحقق المرجعية لكل مرحلة قادمة (استخدمها حرفيًا)
1. لا بروتوكول موازٍ — امتداد للأحداث القائمة (`rc:*` / `screen:*` / `cam:*` / NexusLive).
2. لا كرِيت/حزمة قبل التحقق من مصدرها + إثبات وجود الميزة المستخدمة.
3. كل ميزة حساسة للأداء فوق NexusLive (UDP) — socket.io للإشارات والتدقيق فقط.
4. عربي/إنجليزي من نفس القاموسين (web: i18n بالمكوّنات · Flutter: `assets/translations/{ar,en}.json` بنمط nested keys).
5. ويندوز/لينكس/ماك في كل مرحلة — القيود بصدق (§3 أعلاه).
6. E2E جديد لكل ميزة + commit منطقي لكل وحدة + تحديث §18/اللاحق في العقد.
7. v1.0.0 مقفولة — لا مساس بالإصدار/الوسم/الأصول الموقعة.
8. الحاوية بلا GUI/هاتف حقيقي — الإثبات: محركات verify تنفيذية + E2E تعاقدي + CI بنائي 3 منصات + بروتوكول اختبار ميداني موثق.
